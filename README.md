# 3D Vision Lab Final

Submission work for the 3D Vision for Multiple and Moving Cameras lab evaluation.

## Main Files

- `Roy_Gourab_1.m`: Section 1 camera calibration.
- `Roy_Gourab_2.m`: Section 2 feature matching and geometric verification.
- `Roy_Gourab_3.m`: Section 3 multi-view reconstruction.
- `latex_report/Roy_Gourab.pdf`: final report PDF.
- `Roy_Gourab_Submission_Ready/`: folder prepared for final submission.

## Notes

The scripts expect the `images/`, `results/`, `lib/`, and `vlfeat-0.9.21/` folders to be available in the project root.
